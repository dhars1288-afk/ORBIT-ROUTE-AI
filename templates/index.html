📐 Q-Learning Formulation & Reward Scheme

Bellman Equation:
Q(s, a) ← Q(s, a) + α [ R + γ max Q(s', a') - Q(s, a) ]
  • State (s): Current Satellite + Destination Target (SAT_i, SAT_dst)
  • Action (a): Forward packet to adjacent neighbor satellite
  • Positive Reward (+120): Packet successfully delivered to destination
  • Penalties: - (0.35·Delay + 0.30·Loss + 0.20·Energy + HopCost)
  • Loop Prevention (-45): Cycle detected in routing path

🚨 The Problem

Low Earth Orbit (LEO) satellites travel at ~7.5 km/s, causing rapid topology changes, intermittent line-of-sight occlusions, Doppler shifts, and buffer congestion. Traditional static shortest-path routing (e.g. Dijkstra based on distance alone) causes severe packet drops and excessive satellite power drain.

💡 OrbitRoute AI Solution

A hybrid intelligent routing framework that combines Supervised Machine Learning (Random Forest) to score multi-objective link viability and Reinforcement Learning (Q-Learning) for dynamic topology adaptation. It continuously optimizes: 0.35·Delay + 0.30·Loss + 0.20·Energy + 0.15·Hops.

🎓 High-Yield Viva Questions & Answers

Q1: Why is traditional Dijkstra insufficient for satellite networks?

Answer: Dijkstra minimizes a single additive metric (typically hop count or geographic distance). In satellite networks, the shortest physical distance path often encounters congested router buffers, high Doppler shifts, or depleted satellite batteries. OrbitRoute AI optimizes a composite multi-objective cost function incorporating delay, packet loss, energy, and queue status.

Q2: How does the Random Forest model determine route optimality?

Answer: The Random Forest Classifier is trained on 14 telemetry features. It outputs a class probability P(Optimal) reflecting whether the link parameters fall within the top 38th percentile of high-quality, stable communication channels.

Q3: How does the Q-Learning agent prevent routing loops?

Answer: The state is defined as (Current_Satellite, Destination_Satellite). During path exploration, an active visited list tracks traversed nodes. If the agent attempts to revisit an already traversed satellite, a severe negative reward (-45 penalty) is applied, discouraging cycles via Bellman backpropagation.

Q4: How are satellite movements modeled in the simulation?

Answer: Satellites are initialized in two complementary orbital planes (Plane A and Plane B) using Keplerian angular coordinates. In each simulation step, satellites advance along their orbits at 7.56 km/s, recomputing Euclidean distances, free-space path loss, and dynamic queuing delays in real time.
